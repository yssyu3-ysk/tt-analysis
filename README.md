# 卓球 試合分析ツール（iPhone Safari対応版）

- 1球目 / 2球目 / 3球目 / 4球目 / 5球目以降を独立して記録
- 得失点の原因を別項目として記録
- 各ゲームのサービス／レシーブ時の得点・失点を自動集計
- 試合日・対戦相手・試合メモ
- スクショ用ダッシュボード
- 複数試合をlocalStorageに保存・呼び出し・削除
- JSON / CSVバックアップ
- 動画は端末内で再生し、サーバーへアップロードしない

重要な試合データはJSONでバックアップしてください。localStorageは同じ端末・同じブラウザ内で保持され、SafariのWebサイトデータを消去すると失われる可能性があります。
